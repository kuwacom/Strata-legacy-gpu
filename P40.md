# Tesla P40 (sm_61) work in this fork

This fork carries machine-specific experiments and notes for running Strata's
`qwen4exp` engine (Qwen3.8-Flash-Next) on a single Tesla P40, including a 512K
context configuration and prefill/decode tuning for compute capability 6.1.

- **Summary and results:** [`docs/p40/README.md`](docs/p40/README.md)
- **Final accepted configuration:** `main` (see `docs/integration/v3.md`)
- **Experiments:** the `docs/*` and `perf/*` branches keep the per-worktree history
  (research, kernel maps, 512K feasibility, MMQ tiles, sm_61 defaults, fusion,
  prefill GDN/QSA, decode sweeps, and the v2/v3 integrated builds).

No model files, API keys, or local run logs are committed. Build outputs
(`engines/`), partial downloads, and results directories are excluded.

The numbers in these notes come from one P40 with 98 GiB of RAM and a
SATA-class disk. They are not a claim about other cards or configurations.
