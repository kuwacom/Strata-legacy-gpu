## 判定とリスク

**判定（サブの提案）: 本番切替は可。ただし decode は改善しない（5% 閾値の内側）ので、切替の根拠は prefill と TTFT。**

- prefill +17.7〜20.4%、TTFT -14.3〜-16.6% は 5% 閾値を大きく超え、再現性もある。GDN dense MMQ 単体の寄与は
  +13.2〜15.0%（B0 対照）。残り（+3.5〜4.7%）は engine 0.1.57 と統合 3 パッチ
- decode は -3.9〜+2.6% で、A 同士の揺れと同程度。sm_61 既定の decode 改善（統合タスクで +2.5% 前後）は
  今回の A/B では確認できなかった（engine 差と相殺している可能性。推定）
- 品質は needle 32K/128K・QA 8 問・KL で A と同等。480K も B は正解。bitwise ではないが、KL は小さく top-1 は一致
- パリティ 24/24 PASS、起動・回答とも正常。`libstrata_kq.so` に Q3_K が入り、engine ログで dense MMQ と
  K-quant ライブラリのロードを確認した

リスクと注意:

- **engine 0.1.52 -> 0.1.57 の更新を含む**。今回の A/B は本番イメージと v2 の比較なので、バージョン差と
  パッチ差が分離できていない（B0 対照で統合相当は +3.5〜4.7%）。バージョン差そのものは未測定
- `STRATA_DENSE_MMQ=1` と `STRATA_MMQ_KQ=1` は opt-in。本番の `STRATA_SET`（`~/opt-work/prod.env`）に
  この 2 つを足さないと GDN の改善は効かない（既定 off のまま）
- `STRATA_MMQ_KQ=1` は K-quant expert 経路も開ける。このモデルの expert は IQ3_XXS なので実質影響なし
- `libstrata_kq.so` が +1.03 MB（6.12 -> 7.16 MB）。VRAM はモデル起動時にライブラリをロードする分だけ増える（未計測）
- 480K では qsa select が支配的で改善は小さい（128K の +18% が 480K では数 % に落ちる。推定）
- 計測は他タスクとの GPU/CPU 競合があった。1 回目（22:13）の B は CPU 36-47 を共有するビルドが同時に走り、
  decode が最大 -30% 振れたため破棄して 22:27 に取り直した（`arms/B1v-contaminated/`）。以降は
  「ビルドロック無し・他コンテナ無し」を確認してからロックを取る方式に変えた
- A の回答は実行ごとに揺れる（8K/16K）。品質の受け入れ判定に文字列一致を使わないこと

## ロールバック手順

切替後に問題が出た場合（旧イメージ・`prod.env`・preset を戻す）:

1. `~/opt-work/prod.env` の `STRATA_IMAGE` を `ghcr.io/niko1221/strata:0.2.7-cuda12` に戻す
   （切替時に `strata:fork-v2` へ変えていた場合）。`STRATA_SET` から `STRATA_DENSE_MMQ=1` `STRATA_MMQ_KQ=1` を外す
2. `cp ~/opt-work/prod.env ~/Strata/docker/compose/.env`
3. `sudo docker exec strata sh -c "strata launch --stop --preset docker >/dev/null 2>&1; strata launch --delete-preset docker"`
   （preset を必ず消してから作り直す。`--set` の値が残るため）
4. `cd ~/Strata/docker/compose && sudo docker compose -f docker-compose.nvidia.yml -f docker-compose.override.yml up -d --force-recreate`
5. `sudo docker inspect -f "{{.State.Health.Status}}" strata` が healthy になるまで待つ。engine の cmdline が
   `--max-context 524288 --kv int8 --kv-resident 32768 --ple-io ram --prefill auto --rope-scaling yarn
   --rope-scale 2 --spec 4 --spec-min-p 0.5` であること、`STRATA_` 環境が `STRATA_DENSE_F32=1` だけであること、
   preset `docker.json` に計測用の `--set` が無いことを確認する
6. 旧イメージが残っていること（`sudo docker images | grep 0.2.7`）を確認。消していても ghcr から再取得できる
   （ダウンロードは禁止のため、切替前に残っていることを確認しておく）
