- needle はすべて正解で、A と B で差がない（32K/128K）。480K も B は 2 本とも正解
- QA 8 問は A と B で回答文がバイト一致（`1. Dr. Vera Lindqvist` 〜 `8. 3`）。wall は -26.6%
- KL は logits dump（`STRATA_LOGITS_DUMP`）を (pos, T) で突き合わせた。dump には品質ステージの
  全リクエストが入るため、needle の行は ID が異なり比較不能（除外。pos 32123 / 125007 の
  KL 9.9 / 9.5 は needle 本文が違うだけの見かけの値）。同一プロンプト（KL 4K/24K、QA、固定 4 プロンプト）の

  A-B の差はノイズ床の 1.7 倍。top-1 は一致
- 固定 4 プロンプトの回答は A 自身が 8K/16K で揺れ（4 行差）、B 自身も 16K で揺れる（4 行差）。
  A-B の差（7〜10 行）はこの揺れと同程度で、内容は同じ（Fibonacci の docstring の書き方だけが違う）。
  文字列一致は品質ゲートに使えない（v2 と同じ結論）

## 判定とリスク

**判定（サブの提案）: 本番切替は可。根拠は prefill と TTFT（特に 480K）。decode は改善しない。**

- prefill +22.6〜36.3%、TTFT -18.5〜-26.6% は 5% 閾値を大きく超え、再現性もある。
  480K は TTFT -34.5%、prefill +52.8% で、v2 の 23 分が 15 分弱になる
- 内訳は「engine 0.1.57 + 統合 3 パッチ + GDN dense MMQ」が +18.0〜20.9%（B0v3 対照）と
  「QSA select thread scorer」が 128K で +14.5〜15.4%（B1v/B0v3）。両方とも再現性がある
- decode は -3.2〜+3.2%（4K prose の 1 本の外れ値 35.39 は別ブロックの再計測で 43.27 と確認）で、
  A 同士の揺れと同程度。5% 閾値に届かない
- 品質は needle 32K/128K/480K・QA 8 問・KL で A と同等。bitwise ではないが、KL は A 自己の
  ノイズ床と同程度で top-1 は一致
- パリティ 34/34 PASS、起動・回答とも正常。`libstrata_kq.so` に Q3_K が入り、engine ログで
  dense MMQ と K-quant ライブラリのロードを確認した

リスクと注意:

- **engine 0.1.52 -> 0.1.57 の更新を含む**。A/B は本番イメージと v3 の比較なので、バージョン差と
  パッチ差は分離できていない。QSA の寄与だけは B0v3（`STRATA_SCORES_THREAD=0`）で分離した。
  バージョン差そのもの（0.1.57 + 統合 3 パッチ + GDN）は B0v3 の本番比 +18.0〜20.9% で、
  v2 タスクの B0（統合相当）+3.5〜4.7% と GDN +13.2〜15.0% の合計とほぼ一致する
- 0.1.57 は launch 引数が変わる。本番の `--spec-min-p 0.5` の代わりに dflash2 の draft
  （`--draft dflash2 --draft-model ... --draft-fallback none --draft-conf 0.7`）が入る。
  decode の A/B はこの違いを含む（`arms/B1v/engine-cmdline.txt` と `arms/A1/engine-cmdline.txt` を比較）
- `STRATA_DENSE_MMQ=1` と `STRATA_MMQ_KQ=1` は opt-in。本番の `STRATA_SET`（`~/opt-work/prod.env`）に
  この 2 つを足さないと GDN の改善は効かない（既定 off のまま）
- `STRATA_SCORES_THREAD` は sm_61 で既定 thread（パッチ）。`STRATA_SCORES_THREAD=0` で warp に戻せる
- `STRATA_MMQ_KQ=1` は K-quant expert 経路も開ける。このモデルの expert は IQ3_XXS なので実質影響なし
- `libstrata_kq.so` が +1.03 MB（6.12 -> 7.16 MB）。VRAM はモデル起動時にライブラリをロードする分だけ増える（未計測）
- v3 イメージは**ローカルのみ**（ghcr へ push していない）。ホストから消すと戻せないので、切替前に
  `sudo docker images | grep fork-v3` で存在を確認する
- 480K の TTFT 889 s は 1 リクエストあたり。60 分の GPU ロック内で 2 本まで（3 本目は超える）
- 計測は 1 ブロック 60 分以内に収めた（最長は B0v3 の 40 分、A1 45 分、B480 40 分、B1vd 12 分）。
  各ブロックの終わりに本番を復元してからロックを解放した（復元ログ `restore-*.txt` 8 本）
